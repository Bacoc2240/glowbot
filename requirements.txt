# Dependencias de GlowBot, con version fija.
#
# Por que se fijan: sin `==`, cada despliegue de Railway resuelve la ultima
# version publicada de cada paquete. Eso significa que un despliegue que solo
# cambia una plantilla puede traer una version nueva de DRF o del cliente de
# Anthropic, y si algo se rompe no hay forma de distinguir si fue el cambio
# propio o la dependencia. Fijar convierte el despliegue en reproducible: el
# mismo commit instala siempre lo mismo.
#
# Aqui se fijan solo las dependencias DIRECTAS, las que el codigo importa. Las
# transitivas (anyio, pydantic, urllib3 y demas) las resuelve pip. Si algun dia
# hiciera falta reproducibilidad total --incluidas las transitivas--, el
# instrumento es un archivo aparte generado con `pip freeze`, no engordar este,
# que dejaria de decir que usa el proyecto y pasaria a decir que hay instalado.
#
# Para subir una version: cambiarla aqui, correr la suite completa en local y
# commitear ese cambio solo, para poder revertirlo aislado si el despliegue
# falla.
